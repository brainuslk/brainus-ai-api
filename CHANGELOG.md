# Changelog

## 1.0.0

- Query Sri Lankan curriculum content with AI-generated answers and source citations
- Subject and grade filters to scope queries to specific curriculum areas
- Model selection — `brainusai-fast` and `brainusai-thinking`
- API key authentication and management
- Usage stats, quota tracking, and plan listing
- Python SDK (`pip install brainus-ai`) — async, typed, automatic retries
- JavaScript / TypeScript SDK (`npm install @brainus/ai`) — ESM/CJS, zero dependencies
- Developer portal at [developers.brainus.lk](https://developers.brainus.lk) with API playground and analytics
