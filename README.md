# BrainUs AI API

[![Documentation](https://img.shields.io/badge/docs-developers.brainus.lk-blue?style=flat-square)](https://developers.brainus.lk/docs) [![PyPI](https://img.shields.io/pypi/v/brainus-ai?style=flat-square&label=PyPI)](https://pypi.org/project/brainus-ai/) [![npm](https://img.shields.io/npm/v/@brainus/ai?style=flat-square&label=npm)](https://www.npmjs.com/package/@brainus/ai) [![Discord](https://img.shields.io/badge/Discord-join-5865F2?style=flat-square&logo=discord&logoColor=white)](https://discord.gg/3Y7KsR7qcW)

BrainUs AI is a RAG-powered API that gives your applications access to Sri Lankan curriculum content — textbooks, syllabuses, and educational materials across all grades and subjects. Query in natural language, get AI-powered answers with source citations.

> This is the **public community repository** for BrainUs AI API. The service code is private. Use this repo to file bugs, request features, browse documentation, and explore code examples.

**Learn more in the [official documentation](https://developers.brainus.lk/docs).**

## Get started

Get an API key at [developers.brainus.lk](https://developers.brainus.lk), then install an SDK:

```bash
pip install brainus-ai       # Python
npm install @brainus/ai      # JavaScript / TypeScript
```

For a full walkthrough, see the [quick start guide](https://developers.brainus.lk/docs/quick-start).
